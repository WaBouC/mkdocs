ASCII_ART

import PIL.Image
On importe Image de la bibliothèque PIL, cela permet de travailler avec des images

img_flag = True
path = input("Enter the path to the image field : \n")
img_flag est une variable

path récupère du clavier le chemin du fichier image que l’utilisateur souhaite transformer.

try:
    img = PIL.Image.open(path)
    img_flag = True
except:
    print(path, "Unable to find image ")
Le programme essaie d’ouvrir l’image avec PIL.Image.open(path)

Si le chemin est incorrect ou l’image introuvable, il affiche un message d’erreur

width, height = img.size
aspect_ratio = height / width
new_width = 120
new_height = aspect_ratio * new_width * 0.55
img = img.resize((new_width, int(new_height)))
width, height -> taille d’origine de l’image.

aspect_ratio -> rapport hauteur/largeur, pour ne pas déformer l’image.

new_width = 120 -> largeur finale fixée

new_height -> on calcule la hauteur en fonction du ratio, et on multiplie par 0.55 pour corriger la différence entre pixels et caractères

img.resize((new_width, int(new_height))) -> redimensionne l’image.

img = img.convert('L')
Cela simplifie le passage à des caractères ASCII.

chars = ["@", "J", "D", "%", "*", "P", "+", "Y", "$", ",", "."]
Liste de symboles utilisés pour représenter les pixels

pixels = img.getdata()
new_pixels = [chars[pixel // 25] for pixel in pixels]
img.getdata() -> renvoie une liste contenant la valeur en gris de chaque pixel (entre 0 et 255).

pixel // 25 → on divise par 25 pour ramener les valeurs à un index de 0–10

new_pixels = ''.join(new_pixels)
new_pixels_count = len(new_pixels)
ascii_image = [new_pixels[index:index + new_width] for index in range(0, new_pixels_count, new_width)]
ascii_image = "\n".join(ascii_image)
''.join(new_pixels) -> transforme la liste de caractères en une longue chaîne de texte.

On coupe cette chaîne en lignes de longueur égale à new_width

"\n".join(...) -> ajoute des sauts de ligne pour obtenir une vraie image ASCII lisible. 

with open("ascii_image.txt", "w") as f:
    f.write(ascii_image)
Le résultat est écrit dans un fichier texte appelé ascii_image.txt
